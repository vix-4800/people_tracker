# Учёт перемещений — план реализации

Цель: автономное клиентское PWA по предоставленному ТЗ.
Стек: Vue 3, TypeScript, Vite, Dexie, vite-plugin-pwa, Vitest.
Пользователь поручил самостоятельную реализацию без остановки на проектировании.

Архитектура: чистая машина состояний в domain; транзакционное хранилище в data; реактивная подписка Dexie в composables; отдельные компоненты списка, панели действий, журнала и настроек. Pinia для одного локального хранилища не требуется.

- [x] Модели и тесты переходов: прибытие, перемещение, повтор, убытие, возвращение, уход, явное возобновление, отмена, разделение дней.
- [x] IndexedDB и тесты транзакций, архива, резервных копий и валидации импорта. Схема v1 → v2 с миграцией порядка справочников.
- [x] Адаптивный русский интерфейс, справочники, журнал, фильтры, темы, обработка ошибок и смены даты.
- [x] PWA, локальные иконки, обновление по запросу, документация.
- [x] TypeScript, Vitest, production build, проверка браузера и офлайн-режима.

Решения: прошлые дни только для чтения; отмена удаляет последнее событие сотрудника за сегодня; архивный кабинет остаётся видимым для текущих находящихся в нём сотрудников; архивные сотрудники доступны в журнале. Резервная копия заменяет базу целиком после проверки и подтверждения. Импорт проверяет цепочки переходов и ссылки, сохраняет локальную дату события независимо от часового пояса восстановления.

Особое внимание: параллельные вкладки, полночь и возврат из фона, повреждённые копии, отказ IndexedDB и persistent storage, недопущение дублирования отметок.

Проверено: 19 тестов Vitest; vue-tsc без ошибок; production build и генерация SW успешны. Независимое статическое ревью выявило устаревшее подтверждение импорта; исправлено, добавлены два регрессионных теста. Физическая установка на Android/Windows требует проверки на соответствующем устройстве.

Браузерный production-сценарий Chrome прошёл: мобильный экран 390×844, создание справочников, шесть типов событий, отмена, общий журнал, смена тем, JSON round-trip и сброс подтверждения после повреждённого файла; service worker активен; офлайн-перезагрузка, запись новой отметки без сети и сохранение после повторной перезагрузки. Проверен desktop 1440×1000, нет горизонтального переполнения и ошибок страницы. Скриншоты визуально проверены. Локальный системный прокси обходится только тестовым Chrome для доступа к loopback; настройки пользователя не меняются.
